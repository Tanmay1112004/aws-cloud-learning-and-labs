# AWS Cloud Learning and Labs

A structured repository documenting my AWS Cloud learning journey, course notes, hands-on labs, troubleshooting, and interview preparation.

## About This Repository

This repository contains notes and practical exercises covering AWS services and cloud infrastructure concepts. It is organized by AWS service to make learning, revision, and interview preparation easier.

- Amazon EC2

- Amazon S3
- Amazon VPC
- Elastic Load Balancing
- Auto Scaling
- AWS IAM
- Amazon RDS
- Amazon DynamoDB
- AWS Lambda
- Amazon SQS
- Amazon SNS
- Amazon CloudWatch
- AWS CloudTrail
- Amazon Route 53
- AWS CloudFormation
- AWS Elastic Beanstalk
- Amazon Lightsail

## Learning Approach

For each AWS service, I document:

- What the service is
- Why it is used
- How it works
- Important AWS concepts
- Console walkthroughs and commands
- Architecture diagrams
- Common errors and troubleshooting
- Interview questions and scenarios
- Hands-on practice
