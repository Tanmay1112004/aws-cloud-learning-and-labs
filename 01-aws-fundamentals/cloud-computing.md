# Cloud Computing

## What Is Cloud Computing?

Cloud computing means using computing resources over the internet instead of buying and maintaining physical hardware ourselves.

These resources can include:

- Servers — run applications and websites.
- Storage — store files and data.
- Databases — manage application data.
- Networking — connect systems.
- Software — use applications online.

### Real-Life Example

Cloud computing is similar to electricity. We do not need to build our own power station. We use electricity when needed and pay according to consumption.

Similarly, cloud computing lets us use computing resources when required.

## Traditional Computing vs Cloud Computing

| Traditional Computing | Cloud Computing |
|---|---|
| Buy physical servers. | Create or rent cloud servers. |
| Pay upfront for hardware. | Often pay based on usage. |
| Maintain physical infrastructure. | Cloud provider manages underlying infrastructure. |
| Scaling may require purchasing hardware. | Resources can often be increased or decreased quickly. |
| Hardware setup may take time. | Resources can often be created in minutes. |

## Five Characteristics of Cloud Computing

### 1. On-Demand Self-Service

Users can create resources such as servers when needed without asking the provider to manually provision them.

### 2. Broad Network Access

Cloud services can be accessed over a network using devices such as laptops, smartphones, and desktops.

### 3. Resource Pooling

The cloud provider shares underlying infrastructure among customers while maintaining logical isolation between their resources and data.

### 4. Rapid Elasticity

Resources can be increased or decreased quickly according to workload demand.

### 5. Measured Service

Resource usage is measured so that charges can be calculated according to the service's pricing model.

## Cloud Service Models

### IaaS — Infrastructure as a Service

Provides virtual machines, storage, and networking.

The customer manages the operating system and applications.

**Example:** Launching a Windows EC2 instance.

### PaaS — Platform as a Service

Provides a platform for building and deploying applications without managing all the underlying infrastructure.

### SaaS — Software as a Service

Provides ready-to-use software over the internet.

**Examples:** Web-based email and online document editing.

### Easy Way to Remember

- IaaS = Infrastructure
- PaaS = Application development platform
- SaaS = Ready-to-use software

## Cloud Deployment Models

### Public Cloud

Cloud services run on a provider's infrastructure and are offered to multiple customers.

### Private Cloud

Cloud infrastructure is dedicated to one organization.

### Hybrid Cloud

Combines public cloud and private cloud environments.

## Benefits of Cloud Computing

- Cost efficiency
- Scalability
- Accessibility
- Reliability features
- Security tools
- Reduced maintenance of physical infrastructure
- Faster resource provisioning

## Challenges of Cloud Computing

- Internet dependency
- Data privacy concerns
- Less control over physical infrastructure
- Potential cloud provider downtime
- Incorrect configuration can create security risks

**Important:** Cloud computing does not automatically guarantee zero downtime or perfect security. Proper configuration, backups, permissions, and monitoring are still required.

## Introduction to AWS

AWS stands for **Amazon Web Services**.

AWS provides cloud services such as virtual servers, storage, databases, networking, security, and monitoring.

### Common AWS Use Cases

- Website hosting
- Data storage and backups
- Application development and testing
- Big data and analytics
- Artificial intelligence and machine learning
- Video streaming and gaming

### Important AWS Services

| AWS Service | Purpose |
|---|---|
| Amazon EC2 | Virtual servers |
| Amazon S3 | Object storage |
| Amazon RDS | Managed relational databases |
| Amazon VPC | Networking environment |
| AWS IAM | Identity and access management |
| Amazon CloudWatch | Monitoring and metrics |
| Amazon Route 53 | DNS and domain routing |

## Interview Questions

### Q1. What is cloud computing?

Cloud computing means using servers, storage, databases, and networking over the internet instead of managing physical hardware ourselves. We can create resources when needed and pay according to usage.

### Q2. What are the benefits of cloud computing?

The main benefits are cost efficiency, scalability, accessibility, reliability features, and reduced infrastructure maintenance.

### Q3. What is the difference between IaaS, PaaS, and SaaS?

IaaS provides infrastructure, PaaS provides a platform for application development and deployment, and SaaS provides ready-to-use software.

### Q4. What is AWS?

AWS stands for Amazon Web Services. It is a cloud platform that provides services such as EC2, S3, RDS, and VPC to host applications, store data, and build cloud infrastructure.

### Q5. Does cloud computing guarantee perfect security?

No. Cloud security depends on correct configuration, access controls, backups, monitoring, and the responsibilities of both the provider and customer.
